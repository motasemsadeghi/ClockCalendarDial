# ساعت چهارتکه (Quarter Clock)

یک ساعت آنالوگ با ایدهٔ متفاوت: هر عقربه فقط یک چهارم دایره را طی می‌کند. وقتی به انتهای مسیرش می‌رسد برمی‌گردد و مقیاس عوض می‌شود. صفحه هم هر ۶ ساعت می‌چرخد و محور عقربه‌ها به گوشهٔ بعدی می‌رود.

*An analog clock where every hand sweeps only a quarter circle, then returns while the scale changes. The whole page rotates every 6 hours.*

## چطور کار می‌کند

- **ثانیه‌شمار:** ۹۰ درجه را در ۱۵ ثانیه می‌رود. بازه‌ها: ۰ تا ۱۵، ۱۵ تا ۳۰، ۳۰ تا ۴۵، ۴۵ تا ۰.
- **دقیقه‌شمار:** ۹۰ درجه را در ۱۵ دقیقه می‌رود، با همان چهار بازه.
- **ساعت‌شمار:** ۹۰ درجه را در ۶ ساعت می‌رود. بازه‌ها: ۰ تا ۶، ۶ تا ۱۲، ۱۲ تا ۱۸، ۱۸ تا ۲۴.
- پایان هر بازه: عقربه با انیمیشن برمی‌گردد و اعداد مقیاس عوض می‌شوند.
- پایان هر ۶ ساعت: کل صفحه ۹۰ درجه می‌چرخد و محور از پایین‌چپ به بالاچپ، بالاراست و پایین‌راست می‌رود. اعداد همیشه مستقیم و خوانا می‌مانند.

## امکانات

- حرکت نرم و پیوستهٔ همهٔ عقربه‌ها
- سه کمان مقیاس هم‌مرکز (ثانیه، دقیقه، ساعت) با اعداد فارسی
- حالت روشن و تیره خودکار، بر اساس تنظیم دستگاه
- قابل نصب به‌صورت اپ (PWA) و کار آفلاین
- بدون هیچ کتابخانه یا ابزار ساخت، فقط HTML و CSS و جاوااسکریپت ساده

## اجرا

فایل `index.html` را در مرورگر باز کنید. نصب یا ساخت لازم نیست.

برای قابلیت نصب و آفلاین، فایل‌ها باید از یک آدرس `https` سرو شوند (مثلاً GitHub Pages).

## انتشار روی GitHub Pages

1. همهٔ فایل‌ها را در ریشهٔ مخزن آپلود کنید.
2. در `Settings` و بعد `Pages`، شاخهٔ `main` و پوشهٔ `root` را انتخاب کنید و `Save` بزنید.
3. بعد از یکی دو دقیقه آدرس سایت بالای همان صفحه نوشته می‌شود.

## نصب به‌صورت اپ

- **آیفون (Safari):** دکمهٔ اشتراک‌گذاری، سپس `Add to Home Screen`
- **اندروید (Chrome):** منوی سه‌نقطه، سپس `Install app`
- **کامپیوتر (Chrome یا Edge):** آیکن نصب در نوار آدرس

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | خود ساعت (کد و ظاهر) |
| `manifest.webmanifest` | اطلاعات نصب اپ |
| `sw.js` | کار آفلاین |
| `icon-192.png`، `icon-512.png` | آیکن اپ |

## ویجت آیفون (اختیاری)

برای برنامهٔ Scriptable یک اسکریپت ویجت کوچک هم هست (`QuarterClockWidget.js`) که عقربه‌های دقیقه و ساعت را رسم می‌کند. چون iOS ویجت‌ها را فقط هر چند دقیقه یک بار تازه می‌کند، ثانیه‌شمار ندارد.
